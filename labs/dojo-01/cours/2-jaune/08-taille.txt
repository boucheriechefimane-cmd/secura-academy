# Defi d08 - Le compte exact

Ceinture 2 (jaune)

Outil attendu : wc

Le fichier paquets.log contient un nombre précis de lignes.
Rapporte ce nombre sous la forme SECURA{N_lignes}.
Indice : « wc -l paquets.log » — le compte, pas l'estimation.

Le drapeau n'est ecrit nulle part dans les documents du dojo :
il est lu par le serveur, en root, dans /root/flags.
