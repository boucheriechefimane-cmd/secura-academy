# Defi d05 - Le fichier protégé

Ceinture 2 (jaune)

Outil attendu : ls -l, ls -la

Le dossier /srv/dojo/2-jaune/coffre/ contient trois fichiers.
Deux sont lisibles, un est protégé (droits 000). Le drapeau est
le NOM du fichier protégé, entouré des accolades habituelles.
sans son extension .txt.
Indice : « ls -la coffre/ » montre les droits même quand tu ne peux
pas lire le contenu.

Le drapeau n'est ecrit nulle part dans les documents du dojo :
il est lu par le serveur, en root, dans /root/flags.
