# Defi d03 - La valeur cachée dans les lignes

Ceinture 1 (blanche)

Outil attendu : grep, head, tail

Le fichier inventaire.txt contient 40 lignes. Une seule porte la
mention « cle ». Rapporte la valeur qui la suit.
Indice : « grep cle inventaire.txt » — une ligne, pas quarante.

Le drapeau n'est ecrit nulle part dans les documents du dojo :
il est lu par le serveur, en root, dans /root/flags.
