# Defi d14 - Le type de fichier

Ceinture 4 (verte)

Outil attendu : file

Trois fichiers sans extension. Un seul est un exécutable ELF.
Rapporte son nom sous la forme SECURA{nom}.
Indice : « file * » dans /srv/dojo/4-verte/.

Le drapeau n'est ecrit nulle part dans les documents du dojo :
il est lu par le serveur, en root, dans /root/flags.
