# Defi d11 - La règle du pare-feu

Ceinture 3 (orange)

Outil attendu : cat, grep

pare-feu.conf autorise plusieurs ports. Rapporte celui qui devrait
être fermé : la règle porte le commentaire « temporaire ».
Forme : SECURA{port_NNNN}.
Indice : « grep temporaire pare-feu.conf ».

Le drapeau n'est ecrit nulle part dans les documents du dojo :
il est lu par le serveur, en root, dans /root/flags.
