# Defi d09 - Le port qui écoute

Ceinture 3 (orange)

Outil attendu : ss, netstat, cat

Le service du dojo écoute sur un port. Rapporte le numéro de ce
port sous la forme SECURA{port_NNNN}.
Indice : « ss -ltn » liste les ports en écoute ; ou lis
/srv/dojo/3-orange/service.conf, ligne « port = ».

Le drapeau n'est ecrit nulle part dans les documents du dojo :
il est lu par le serveur, en root, dans /root/flags.
