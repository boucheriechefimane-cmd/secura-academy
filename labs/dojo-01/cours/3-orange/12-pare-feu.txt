# Defi d12 - Le processus qui consomme

Ceinture 3 (orange)

Outil attendu : ps, sort, cat

Le fichier processus.txt liste des processus avec leur consommation.
Rapporte le NOM du processus qui consomme le plus de mémoire CPU, sous
la forme SECURA{nom}.
Indice : « sort -k2 -n processus.txt | tail -1 ».

Le drapeau n'est ecrit nulle part dans les documents du dojo :
il est lu par le serveur, en root, dans /root/flags.
