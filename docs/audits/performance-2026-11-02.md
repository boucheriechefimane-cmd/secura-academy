- **Les Core Web Vitals ne se mesurent pas depuis le serveur** — LCP, CLS et INP se mesurent dans le navigateur du visiteur, sur sa connexion. Ce qui est vérifié ici, ce sont les causes racines les plus fréquentes (police distante, script bloquant, image trop lourde, iframe avant clic). La mesure réelle se fera avec PageSpeed Insights sur l'hébergement, une fois le site en ligne.
